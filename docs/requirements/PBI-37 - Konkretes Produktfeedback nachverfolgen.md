# PBI-37 · Konkretes Produktfeedback nachverfolgen

**Planungsstand:** Konzeptentwurf · **Umfang:** Später

## User Story

Als Pilotnutzer möchte ich Beobachtung, Erwartung und Auswirkung erfassen und später nachprüfen, damit Verbesserungen meinen Alltag treffen.

## Akzeptanzkriterien

1. Ein prüfbarer Bericht nennt Ablauf, Beobachtung, Erwartung und Auswirkung; ein Link oder Kopiertext genügt.
2. Vor externer Meldung werden private Inhalte geprüft; kein automatisches GitHub-Issue.
3. Eine spätere Version und erneute Beurteilung lassen sich zur Beobachtung zuordnen; dies ist keine Vorabpilotpflicht.
