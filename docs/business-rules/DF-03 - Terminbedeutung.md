# DF-03 · Terminbedeutung

Zugesagter oder vertraglicher Termin, angegebene formelle Frist, gewünschter Antworttermin und eigene Wiedervorlage bleiben getrennt. Herkunft und Prüfstand einer formellen Frist werden angezeigt; es wird keine rechtliche Fristberechnung zugesichert.

**Abnahmeanker:** Antworttermin 30.11. bleibt bestehen, wenn Wiedervorlage von 23.11. auf 24.11. verschoben wird.

**PBIs:** [[PBI-09 - Termin und Wiedervorlage trennen]], [[PBI-21 - Begründeten Eskalationsschritt prüfen]]
