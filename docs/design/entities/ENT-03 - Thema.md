# ENT-03 · Thema

## Zweck

Optionaler Zusammenhang mehrerer einzeln erledigbarer Punkte innerhalb einer Gemeinschaft.

## Wesentliche fachliche Angaben

Bezeichnung des Themas; Gemeinschaftsbezug; zugehörige Punkte.

## Beziehungen

Ein Thema bündelt mehrere Punkte derselben Gemeinschaft. Punkte dürfen ohne Thema geführt werden. Ob ein Punkt mehreren Themen zugeordnet werden darf, ist im bisherigen Konzept nicht festgelegt.

[[ENT-01 - Gemeinschaft]], [[ENT-04 - Punkt]].

## Regeln und Lebenszyklus

Das Thema hat keinen gemeinsamen Erledigtstatus, der seine Punkte automatisch abschließt. Es setzt keinen vollständigen Handwerkerprozess voraus.

## Modellierungsgrenze und offene Punkte

Eigene gespeicherte Identität oder nur eine benannte Gruppierung ist eine spätere Modellierungsentscheidung.

PRD 1.1: B-FR-03; Fachliches Modell; K-03.
